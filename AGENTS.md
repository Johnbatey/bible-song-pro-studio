# Agent notes

## Commit messages: no AI attribution

This repository does not use AI attribution in its commit history. A commit
message ends at its own last line of description: do not append
`🤖 Generated with Codebuff`, `Co-Authored-By: Codebuff <noreply@codebuff.com>`,
or any equivalent trailer naming an AI tool or assistant. The published
history was rewritten once to strip these trailers from every branch, so
adding one back reintroduces the problem.

Keep the existing Conventional Commit style used by the history, for example
`fix(bible): …`, `build(cuda): …`, `test(settings): …`.
